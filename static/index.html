使用帮助

快速了解 EduTower 各模块的用法

开始之前

在登录页输入称呼即可进入（无需密码）。称呼保存在本机浏览器，用于首页问候与本地聊天记录分组。

请通过 http://localhost:3000 访问（先运行 npm run dev），不要直接双击 HTML 文件，否则样式与接口可能异常。

资料录入

  • 支持文本笔记、网页链接，以及 PDF / Word / 图片上传（单文件最大 20 MB）。
  • 可用文件夹分类管理；上传文件支持在列表中下载。
  • 资料会写入本地数据库，供后续学习计划关联使用。

学习计划与练习

  • 在「学习计划」中创建计划，通过「管理任务」安排每日任务。
  • 练习类任务请关联「技能」，才能在「练习测验」的「按计划任务」下拉框中选用。
  • 生成练习后答题提交，错题会自动进入错题本。

AI 智能复习

  • 在对话区输入问题，Enter 发送，Shift+Enter 换行。
  • 右侧 Agent 面板展示复习进度与今日清单；可从学习计划导入清单项。
  • 历史对话保存在浏览器本地；配置 LLM 密钥后可获得完整 AI 回复。

常见问题

练习页没有计划任务可选？
请先在学习计划中为「练习测验」或「掌握技能」类任务关联技能并保存。
AI 回复异常或提示未配置密钥？
在项目根目录 .env 中配置 LLM_API_KEY，并确保 FastAPI AI Engine 已启动（可选）。
自定义错题分类丢失？
自定义分类会保存到服务器 data/wrongbook-taxonomy.json，请确认后端有写入权限。

产品简介

EduTower 是一款面向学生的 AI 学习助手，将资料管理、学习计划、技能图谱、练习测验、错题本与智能对话整合在同一工作台，帮助你有条理地复习、练习与复盘。

核心能力

  • 学习资料录入与文件夹管理
  • 可编排的学习计划与日任务
  • 技能树与知识图谱可视化
  • 练习生成、自动判分与错题收录
  • AI 助教对话与复习进度面板
  • 学习记忆与偏好记录

技术架构

前端为静态页面 + 原生 JavaScript；后端为 Express + TypeScript + Prisma（SQLite）；AI 能力由 FastAPI Agent 或本地 LLM 接口提供。

版本：0.1.0 · 更新：2026 年

隐私说明

我们如何处理你的学习数据

数据存储位置

  • 服务器本地：学习资料、计划、技能、练习、错题等业务数据存放在本机 SQLite 数据库（dev.db）与 uploads/ 目录。
  • 浏览器本地：登录称呼、AI 聊天历史、部分 Agent 清单项使用 localStorage / sessionStorage，不会自动同步到其他设备。

账号与身份

当前为演示模式：后端使用固定的 Demo 用户，无密码登录。页脚称呼仅用于界面展示，不与服务器账号绑定。

AI 与第三方服务

向 AI 助教发送的消息会转发至你配置的 LLM 服务（如 DeepSeek、OpenAI 兼容接口）。请勿在对话中输入身份证号、银行卡等敏感个人信息。

AI 回复为模型生成内容，不代表平台立场，详见「服务条款」中的免责声明。

你的控制权

  • 可在资料库、错题本、学习计划等模块中删除你创建的内容。
  • 清除浏览器站点数据将删除本地聊天历史与称呼，但不影响服务器上的学习记录。
  • 卸载或删除项目目录将移除全部本地数据库与上传文件。
